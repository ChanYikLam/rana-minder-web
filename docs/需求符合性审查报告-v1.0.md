# RanaMinder 前端需求符合性审查报告 v1.0

> 文档状态：内部审查
> 版本：v1.0
> 日期：2026-08-03
> 审查对象：`rana-minder-web`（Vue3.5 + TS + Pinia + mock 前端，`src/mock` 模拟后端）
> 对照文档：PRD-v1.0（§9 产品能力与用户故事）、组件规范与开发标注-v1.0、状态覆盖规范-v1.0、SRS 状态机转换明细-v1.0

## 1. 审查范围与方法

- 按 PRD §9 的 40 个用户故事（US-ID/ORG/REC/JNT/MEM/FORM/NTF/AUD/STAT/EXP/CFG）逐条核对验收条件；
- 对照组件规范（令牌、双主题、图标三重表达、emoji/色值约束）与状态覆盖规范（五态 + 降级/无权限子场景）做横切核查；
- 以 `文件:行号` 作为证据标注，全部为只读审查。

## 2. 总体结论

**状态机层（29 个 SM、306 条转换）与页面骨架是当前最大资产，核心流程约 60-70% 落地；但存在 4 个页面级 P0 断裂（mock 缺路由导致整页不可用）和大量"死代码/占位实现"。**

- 按 40 个用户故事计：**没有 1 个完全达标（✅）**，全部为"部分满足"，9 个故事存在 P0 级阻断；
- 验收条件符合度约 **40-50%**，不满足 PRD 签署条件；
- 横切项：令牌体系、Lucide 统一、0 emoji、0 硬编码色值、spec-306 测试守护全部达标；双主题组件层 `dark:` 变体覆盖不足；无权限态落地不全。

## 4. P1 缺口清单（验收条件缺失，核心业务不完整）

### 4.1 权限粒度错误（规则级问题，优先于新功能）

- 部门负责人无 `club:interview:evaluate` / `club:recruitment:manage` 权限 → "全量查看+评论全部面试者"与"内部选定录取标签"**整体被权限挡死**（db 层 `db-recruitment.ts:1090-1093` 校验形同虚设）— US-REC-04
- 部门负责人无任何 joint 权限，联合活动"部门负责人默认可查看+评论全部面试者"未实现；查看/结论/邀请共用 `club:joint:manage` 未分权 — US-JNT-03
- 本社团成员可申请本社团招新：`submitApplication` 无成员关系校验 — US-REC-02 / US-ID-01
- 普通成员无法进入部门申请/辞职页：路由要求 `club:member:manage`（普通成员仅 `club:member:view-self`）— US-MEM-02/05

### 4.2 招新与面试链路

- 接受邀请不建立成员关系：`db-recruitment.ts:1213-1221` 仅置 `app.status='accepted'`，无 members 写入 — US-REC-06
- 作废面试不释放时段容量（`slot.taken`）+ 无"已作废、待重新安排"中间态 + 无补面时段新增 API — US-REC-03/07
- 面试官任务分配模型完全缺失（批次级/轮次级、日程占用、跨社团"不可用"+冲突区间展示）— US-REC-03/04/07
- 规则收紧无"暂停报名+补救窗口"：`updateActivity` 直接 `Object.assign` 修改配置，`rule_tightening` 事件为死代码 — US-REC-01
- 改判部门标签通知原设置人、结论发布通知申请人缺失 — US-REC-04
- 身份异常未冻结面试/邀请个人期限、恢复后不顺延 — US-REC-02
- 调剂路径创建（`transfer_path` 事件）无 db 实现；调剂"报名修改截止后锁定"缺失 — US-REC-05
- 首评隔离为空壳：无"他评"数据实体，仅 UI 文案；评价版本覆盖式更新不保留历史 — US-REC-04
- 当前成员禁报/历史成员可报名校验缺失；eligibility 只存不检 — US-REC-02/08

### 4.3 联合活动链路

- 跨社团评分/评语/结论/修改历史实时互见未实现（结论按本社团过滤、评价存页面级 Map）— US-JNT-03
- 联合邀请 `'join'` 类型（未报名社团+服从调剂）不可达：`hasVolunteered` 判断恒真 — US-JNT-04
- 紧急停用社团未立即失权：`canManageJoint` 不检查 `force_suspended` — US-JNT-02
- 冲突提示泄漏对端申请人姓名（"与普通招新面试冲突（刘子豪）"），违反"只显示不可用+冲突区间" — US-JNT-03
- 待复核期间申请人拒绝清除结论 `reviewFlag`（违背"保留待复核义务"）— US-JNT-04
- 结束确认/取消确认期限无过期处理；reopenJointChannel 缺活动终态守卫；强制结束直接置 expired 未走 SM 事件 — US-JNT-01/05
- 同意证据缺"首次公布时锁定社团名单"快照 — US-JNT-02
- 临时联合面试官任务（活动级/轮次级）模型缺失 — US-JNT-03

### 4.4 身份与个人空间

- 同步链路：24h 失败回读恢复无运行时实现；第三值冲突页用硬编码占位数据（`ProfilePage.vue:170-176` 陈小明）且允许用户为姓名/学号选 local（违反"以 Casdoor 当前值为准"）；姓名更正申请（超管审批）整体缺失 — US-ID-03
- 邮箱规则：验证码 5 分钟非 24h、无重发限频、改邮箱后旧邮箱继续有效逻辑缺失；缺失资料用户被路由挡在"查看本人邀请"之外（与 PRD 矛盾）— US-ID-02
- 个人中心：无按社团/业务类型筛选；/me/todo、/me/schedule 为静态数据、待办覆盖不全（缺待补资料/成员生效异常/审批任务）— US-ID-04
- 降级白名单含个人中心（超出"本人基础资料"范围）；"非附件字段"限制无执行点；mock 写端点不校验降级状态 — US-ID-01

### 4.5 成员生命周期

- 邀请有效期硬编码 7 天不可设置（PRD：平台范围内可设，未设用默认值）；资料不完整/邮箱未验证不可接受未实现；候选范围排除其他社团成员/历史成员；`target_already_member`、`sync_failed` 无产生路径 — US-MEM-03
- 辞职申请无撤回功能（无 API/UI）；审批逾期只提醒机制缺失 — US-MEM-05
- 换届方案不支持"卸任/允许空缺部门负责人"；换届角色变化不触发 US-ORG-04 待办续接/预约命令复核；mock 不消费 reauth proof — US-MEM-06
- 审批回退（部门无负责人→社团负责人/人事）未实现；负责人/人事直接添加/移除部门关系无 UI/API；批准/驳回/撤回无通知事实 — US-MEM-02
- 任命候选无姓名子串/学号搜索（纯下拉）；取消预约命令无原因输入；`precondition_failed` 无产生路径与 UI；"辞职必须由职位上级批准"未严格校验 — US-MEM-04
- "标记退出"与"移除"共用同一端点且行为相同；重新加入无演示路径 — US-MEM-05

### 4.6 表单 / 通知 / 审计 / 统计 / 配置

- 纠错：创建表单缺原值/新值字段；mock 无自批校验、无撤回并发控制；逾期撤回仅状态机允许、UI 未实现；无通知联动 — US-AUD-01
- 通知：无"权益事件+通知事实同事务"实现、无按事件对象选择、无去重、无紧急关闭入口（仅状态机）— US-NTF-01
- 邮件：保存不强制测试通过；无"纯内部通知仅站内信"分类；无发件身份选择；无 HTML 注入防护 — US-NTF-02
- 导出：有效期 7 天 vs PRD 24h（页面文案与 mock 双处冲突）；下载 handler 无鉴权；无联系方式显式选择 UI；无联合导出；每次下载无审计 — US-EXP-01
- 统计：无普通/联合分维度；部门负责人数据范围未过滤；admin API 缺失 — US-STAT-01
- 文件：mock 下载无权限校验；水印仅文案；附件替换不创建新版本 — US-FORM-03
- 表单设计器：字段库仅 6 种（缺 number/radio/multi_select/图片）；无校验/条件显示/选项配置 UI；核心字段可任意删除；无复制/平台模板库/超管审核 — US-FORM-01
- 保留策略：默认 365 天 vs PRD 草稿 30 天（可配 14-60）；无 7 天预通知；无文件/日志时限；发布流程缺失 — US-AUD-04
- 学年自动切换、权益期限变更通知、配置分层边界校验缺失 — US-CFG-01
- 正式删除：恢复备份后重新应用删除清单缺失 — US-AUD-03

## 5. P2 缺口清单（次要 / 一致性 / 工程质量）

- explore 数据与 db 脱节：硬编码 `act-002` 在 db-recruitment.ts 中不存在、截止日期写死 2025 年（已过期），目录点击详情 404 — US-REC-08
- 成员模块 `db.ts` 未调用 `assertTransition`（招新模块已用），SM-MEM-* 仅纸面定义，状态机未真正接线
- 列表页状态选项 `pending_casdoor_sync`/`suspended` 无 mock 数据产生路径
- 结论页 expired/rejected UI 分支为死代码（`JointConclusionPage.vue:207-214`）
- 预约命令"内容变化须取消后新建"未强制；`precondition_failed` 状态标签齐备但无任何产生路径
- 同一社团多角色自动合并、显式拒绝项优先、Casdoor 外部变更 5 分钟刷新通知未实现（mock 每社团仅单角色）
- 高风险确认后作用域/权限已变化→拒绝+刷新：仅正式删除页实现（previewVersion），其余页面未实现
- PartialSuccess/ImpactPreview 未在成员/联合模块复用（换届/免职/作废自实现）
- 换届"新任失败时撤回新增"未真实回滚；"旧任移除部分失败"场景未模拟
- 已登录用户访问 /login 无反向重定向
- 状态覆盖规范"无权限"子场景（失权即时/跨社团拒绝/降级期受保护请求关闭）仅 10 个页面使用 PermissionGuard，大量未落地
